# Web Development

RAGE is your co-pilot for full-stack web development.

## Development Workflows
- **Running Commands**: RAGE can run your dev servers (`npm run dev`), install dependencies (`pip install`, `npm install`), and manage your environment.
- **Code Generation**: Tell RAGE what kind of web app you want, and it can write the HTML, CSS (including Tailwind if requested), and JS logic.
- **Automated Testing**: By combining its terminal tools and browser automation, RAGE can run your local web server, open it in the Playwright browser, test the UI, take screenshots, and fix bugs based on visual feedback.
