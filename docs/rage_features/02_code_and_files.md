# Writing Code and Editing Files

RAGE acts like a pair programmer directly in your terminal, equipped with tools to read, write, edit, and search through your files.

## File System Operations
- **File Management**: You can instruct RAGE to create files, rename them, list directories, and search for specific text patterns across your codebase.
- **Code Writing & Editing**: RAGE can help you write scripts, update configuration files, or refactor code by modifying files directly.
- **Git Integration**: Built-in git tools allow RAGE to check status, commit changes, push code, and manage your repositories seamlessly from a natural language prompt.
