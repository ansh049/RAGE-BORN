# Google Workspace Integration

RAGE comes with comprehensive built-in tools for Google Workspace, making it a powerful virtual assistant.

## Features
- **Professional Emails**: Instruct RAGE to draft and send highly professional emails via Gmail. It understands tone and context.
- **Docs and Sheets**: Automate the creation and editing of Google Docs and Sheets directly from the terminal. 
- **Calendar & Meet**: Manage your schedule, create events, and interact with Google Meet.
- **One-Time Login**: With persistent browser profiles, you can log in once using `/glogin` and RAGE will handle the rest of your automation securely.
