# Web Search and Output

RAGE doesn't just execute commands; it can actively seek out information on the internet.

## Web Capabilities
- **Google Search**: Use the terminal to naturally search Google (e.g., "Search Google for Python tutorials") or use the `/searchq` command.
- **Link Extraction & Page Reading**: RAGE can extract links from search results and read web pages to gather context.
- **Formatted Outputs**: The results of its searches can be outputted as formatted markdown in the chat UI, or RAGE can save the research directly into documentation files in your project workspace.
